# Recomendo rodar o projeto VSCODE
### Como rodar:

- Verificar a versão do node.js (instalar caso não tenha):
* node -v
* npm -v

- No vscode:
  * npm install
  * npm install expo@^58.0.0   - para instalar versão atualizada
  * npx expo install --fix
- Para visualizar pelo celular:
  * npx expo start -c
- Para visualizar no pc:
  * npx expo install react-native-web react-dom @expo/metro-runtime
  * npx expo start --web
